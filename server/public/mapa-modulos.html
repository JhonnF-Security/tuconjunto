Flujos principales por rol

ADMIN Administrador (Jorge · 1020001)

  • Resumen: KPIs en vivo + cartera + reservas próximas
  • Comunidad: crear/editar usuarios, roles, aprobar pendientes, reset clave, torres y unidades
  • Pagos: ver todos + asignar cuota manual (o invitar si no existe)
  • Reservas: aprobar ✅ / rechazar ❌ solicitudes
  • PQRS: atender → resolver tickets
  • Crear ▾: ticket, reserva manual, comunicado, asamblea, pago, documento
  • Seguridad: sesión, recordarme ≤12 h, intentos, bloqueo, pass mínima + logo del conjunto
  • Alertas pánico: ver y marcar atendidas

CONSEJO Consejo (Marta · 1020002)

  • Lectura global: KPIs, cartera, usuarios, unidades, stats
  • Ve pagos, reservas y PQRS de toda la comunidad
  • ❌ Sin botones de escritura (bloqueado también en API → 403)

PORTERÍA Portería (Carlos · 1020003)

  • Registrar entrada: nombre, doc, destino + 📷 foto rostro/cédula (cámara o archivo)
  • Panel visitantes: búsqueda en vivo + marcar salida
  • 🚨 Alertas pánico: banner rojo en tiempo real (sondeo 5 s) → atender

RESIDENTE Copropietario / Arrendatario (Ana · 1020004 / Pedro · 1020005)

  • Pagos: estado de cuenta + pagar PSE (simulado) → referencia PG-xxxxx
  • Reservas: zonas comunes por fecha/franja → Pendiente → admin confirma; cancelar propias
  • PQRS: crear con tipo/prioridad → código T-xxxx y seguimiento
  • Asambleas: confirmar asistencia + votar (1 voto/persona)
  • Documentos: descargar PDF/JPG/PNG publicados por admin
  • Comunicados: tablón de avisos
  • 🚨 Botón de pánico: alerta instantánea a portería con su unidad
  • Mi cuenta: cambiar contraseña propia

PÚBLICO Landing comercial

  • Catálogo de módulos, planes Esencial/Profesional/Enterprise
  • Wizard de suscripción: trial 14 días → registra lead
  • Demo interactiva: prototipos admin/residente/portería sin credenciales (/demo)
  • Autorregistro: crea cuenta "Pendiente aprobación"; auto-crea unidad nueva si no existe
  • Términos, privacidad, guía de pruebas

🔒 SEGURIDAD Transversal

  • Contraseñas scrypt · tokens de sesión hasheados sha256
  • CSRF por cabecera en mutaciones · CSP con nonce
  • Rate-limit login 5/min · escrituras 60/min · leads 5/h
  • Magic-bytes en fotos/documentos · SQL 100% preparado
  • Auditoría de acciones sensibles · BD permisos 600
